# CS_330
# How do I approach designing software?

This project helped me learn that designing software is a lot easier when I break everything down into smaller steps. Since working with 3D graphics was completely new to me, I started with the basic shapes and slowly added more to my scene as I went. I worked on things like textures, lighting, colors, and camera movement separately instead of trying to get everything perfect at once. A lot of my design process was making a change, running the program, and deciding if I liked how it looked. If I didn't, I would go back and adjust it. I think this is something I will continue doing with future projects because it made a bigger project feel much more manageable.

# How do I approach developing programs?

Testing as I went was probably one of the biggest things I learned from this project. There were definitely times when I would change one thing and somehow mess up something that was already working. Making smaller changes and testing after each one made it much easier to figure out what went wrong. My scene also changed quite a bit throughout the milestones. I kept making small improvements until I was happy with the final result. By the end of the course, I was a lot more comfortable finding where I needed to make changes in the code and understanding how those changes would affect my scene.

# How can computer science help me in reaching my goals?

This course gave me experience with 3D graphics and helped me get more comfortable working with C++. I learned how shapes, textures, lighting, and camera movement all work together to create a 3D scene. Even if I do not end up working specifically with graphics in the future, I still learned a lot from the process of building and fixing my scene. The problem-solving, testing, and debugging skills I used throughout this project will help me in future courses and in software development. I also think having a project like this in my portfolio is a good way to show how much I have learned and that I can work through something that is completely new to me.
