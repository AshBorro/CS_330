# CS_330
## How do I approach designing software?

This project taught me to take things one step at a time instead of trying to do everything at once. Since 3D graphics were new to me, I started with the basic shapes and slowly added textures, lighting, and camera movement. I mostly made a change, ran the program, and adjusted it until I was happy with how it looked. This is something I can use in future projects because breaking things into smaller steps makes the whole process a lot easier.

## How do I approach developing programs?

Testing as I went was probably the biggest thing that helped me with this project. There were definitely times when I changed one thing and accidentally messed up something else, so testing after smaller changes made it easier to figure out what went wrong. My scene changed a lot throughout the milestones, and I got more comfortable working with the code each time. By the end, I had a much better idea of where I needed to make changes without messing up the rest of my scene.

## How can computer science help me in reaching my goals?

This course gave me experience with 3D graphics, textures, lighting, and camera movement, which were all pretty new to me. Even if I do not end up working specifically with graphics, I can still use the problem-solving and debugging skills I learned in future courses. These skills will also help me professionally because being able to break down a problem, test my work, and keep improving it is important in pretty much any area of software development.
